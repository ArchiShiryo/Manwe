# MANWË — PoC Plan v3.0

## Validation question
Can a user and MANWË look at the same social model, identify an uncertainty, clarify it, correct the model directly and observe an intelligible revision?

## Scope
3 people + 1 group; short history; one main relationship; one Problem; one Goal; two competing hypotheses maximum; one visible Open Question; no D4 deep psychodynamics.

## Vertical slice
1. Backfill/import 10–30 events.
2. Extract Observed / Explicit / User Impression with provenance.
3. Compose a contextual Living Graph.
4. Show one cautious relationship inference plus an alternative.
5. Inspect Why? down to source events.
6. Attach a user correction to a node/evidence item.
7. MANWË opens a discriminating `?` question.
8. User answers; graph and hypothesis visibly revise.
9. A Goal emerges from natural language.
10. MANWË shows two qualitative directions, never a unique correct answer.

## Success criteria
The user understands what is known/inferred/unknown; can correct the model without database-like UI; finds the graph cognitively useful rather than decorative; perceives questions as relevant; sees logical model revision; and gains autonomy rather than dependence.
