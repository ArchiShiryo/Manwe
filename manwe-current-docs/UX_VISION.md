# MANWË — UX Vision v3.0

## Core principle
MANWË is not software to operate. It is a **shared external representation** used by a human and an LLM to understand, question and revise a social situation together.

The interaction loop is **perceive → formulate → confront → clarify → choose → learn**, not navigate → edit → save.

## Living Graph
The Living Graph is the central cognitive surface, not a secondary Network page. It shows only the contextually useful subgraph: people, groups, relations, events, hypotheses, goals, problems, concepts and open questions. The LLM may recompose it as part of an answer.

### Epistemic grammar
- ◆ Explicit — directly stated
- ● Observed — recorded event/behavior
- ≈ User impression — subjective perception reported by the user
- ◇ Inferred — MANWË interpretation
- ? Unknown / Open question — missing information that matters

## Bidirectional collaboration
MANWË may initiate by surfacing a change, opening a question or proposing a cautious hypothesis. The user may select a node/link, inspect `Why?`, attach a correction/comment, or answer a `?` directly. Comments are persistent inputs to the model, not generic chat history.

## Inspector
Selection anchors an Object/Cognition Inspector. The universal path is **claim → explanation → evidence → observation → event/source**. Alternatives, contradictions and uncertainty remain visible.

## Language + spatial representation
A persistent natural-language input can be used to tell MANWË what happened, ask, correct, state an objective, express a problem or answer a question. The response may change both narrative text and the graph focus.

## Goals and Problems
Goals and Problems normally emerge from dialogue rather than SaaS creation forms. The UI materializes them with current state, relevant people, uncertainties and alternative directions.

## Navigation
Primary: Today · People · World · Intentions · Memory. Chat is pervasive. Signals, Research, Sources and Agent diagnostics are deep/secondary surfaces.

## Counselor
Counselor interventions are sparse and contextual. Feedback (`Useful`, `Not useful`, `I already knew this`) drives fading and autonomy.
